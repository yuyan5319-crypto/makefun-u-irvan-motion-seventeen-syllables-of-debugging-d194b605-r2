One haiku about debugging, in strict 5-7-5 syllables — for the make.fun bounty
**Seventeen Syllables of Debugging**.

## The haiku

```
a breakpoint holds still
the log line I buried wakes
it calls me by name
```

Syllable count: 5 – 7 – 5. Total 73 characters (with trailing newline), three lines.

## How to run

```sh
python3 main.py
```

This writes the haiku to `./output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The program
validates the entry before writing: 1–200 characters, exactly three lines.
